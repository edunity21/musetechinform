────────────────────────────────────────────────────────
1. 이것이 무엇인가
────────────────────────────────────────────────────────
「음악 산업 탐구」수업과 웹 플랫폼을 다른 선생님들께 보여 드리는
소개 페이지입니다. 열두 쪽으로 되어 있고, [다음] 을 누르면 화면이
통째로 옆으로 밀려 지나갑니다.

   1. 표지
   2. 왜 이렇게 만들었나   — 걸리던 세 가지와 그 답
   3. 세 차시             — 차시마다 학생이 할 일과 교사가 누를 단추
   4. 열두 분야           — 분야 이름·영문·한 줄 (학생 화면과 같은 표지 색)
   5. 한 분야가 담은 것    — 읽을거리 여섯 겹과 실제 예시 한 장
   6. 활동지 아홉 문항     — 7번을 강조
   7. 채점                — 8 · 8 · 4 = 20점
   8. 1분 발표 영상
   9. 평가가 흔들리지 않게 — 두 개의 자물쇠와 여섯 가지 장치
  10. 교사 화면
  11. 어떻게 만들어졌나    — 깃허브 페이지 + 앱스 스크립트 + 스프레드시트
  12. 맺음말

────────────────────────────────────────────────────────
2. 올릴 파일 (하나뿐입니다)
────────────────────────────────────────────────────────
   index.html

글·그림·동작이 모두 이 한 파일 안에 들어 있습니다.
바깥에서 받아오는 것은 한글 글꼴 하나뿐이고, 그마저 막혀도
컴퓨터에 있는 글꼴로 잘 보입니다.

────────────────────────────────────────────────────────
3. 올리는 방법
────────────────────────────────────────────────────────
 1) github.com 에서 musetechinform 레포지토리를 엽니다.
 2) [Add file] → [Upload files] 를 누릅니다.
 3) index.html 을 끌어다 놓고 [Commit changes].
 4) [Settings] → [Pages] → Branch 를 main / (root) 으로 두고 Save.
 5) 1~2분 뒤 아래 주소가 열립니다.

      https://edunity21.github.io/musetechinform/

────────────────────────────────────────────────────────
4. 고치고 싶을 때 — 어디를 보면 되나
────────────────────────────────────────────────────────
index.html 한 파일 안에서 찾으시면 됩니다.

 · 색 ............ 맨 위 :root { } 안의 --acc 등
 · 열두 분야 ...... 아래쪽 <script> 안의 FIELDS 목록
 · 아홉 문항 ...... 그 아래 QS 목록
 · 글 내용 ........ <section class="pg"> 가 한 쪽입니다. 차례대로 열두 개.
 · 쪽을 더 넣으려면 <section class="pg">…</section> 를 하나 더 붙이고
   data-t="쪽 이름" 만 적어 주면 번호와 넘김은 저절로 맞춰집니다.

학교 이름·연락처는 마지막 쪽(12번) 아래쪽에 있습니다.

────────────────────────────────────────────────────────

 · 실제 수업 사진 한두 장
